# Feylore 0.1.0 — private personal demo

This is a private preview for personal testing. It is not a production-ready release. The preview publishing workflow is independently authorized and does not imply that the full CI workflow passed.

The Docker image runs the API and worker as separate services with PostgreSQL 16. Initial setup, login, health endpoints, startup migrations, persistent application data, and worker recovery received local smoke tests. AMD64 and emulated ARM64 images were built and started locally. The full local test suite previously passed 886 tests with one production-only test skipped; this is not a substitute for GitHub CI validation.

Known limitations and follow-up work:

- Existing databases with an absent or altered migration journal entry, including older installations missing the music entry, require an explicitly verified upgrade procedure. Back up data before upgrading. Use a fresh database for this demo.
- Media scanning, file access, playback, and background processing have not yet been verified end to end in the published image.
- The CI and distribution workflows, published image pull, architecture manifests, SBOM, and provenance still require verification on GitHub.
- Repository lint reports warnings, including React hook dependency warnings. The production-only CSRF test was skipped by the test-mode suite.
- The deployment guide is a draft. Use a trusted HTTPS reverse proxy for access beyond localhost, keep PostgreSQL private, and do not treat this preview as a hardened production service.

Updates are administrator-controlled. Do not grant the container access to the Docker socket.
