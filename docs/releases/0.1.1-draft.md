# Feylore 0.1.1 release notes — draft

This is a release preparation document, not an announcement. Do not publish until the demo seed, image review, deployment checks, and standard CI release workflow have been completed and verified.

Feylore 0.1.1 establishes the first supported installation baseline. A single application container supervises the API and worker; PostgreSQL 16 runs as a separate service. The supplied Compose configuration uses persistent application and database volumes and configurable media mounts. Migrations run before application services start. Administrators complete initial account setup in the browser.

The release assets are intended to include `compose.yaml` and `.env.example`. The intended public image is `ghcr.io/feylore-media/feylore:0.1.1`, with AMD64 and ARM64 support.

Before release, finish and verify optional demo data, scan and review the final image for secrets and private data, exercise the standard release workflow without publishing, and verify the installation guide. Repository and package visibility are handled separately by their administrator.
